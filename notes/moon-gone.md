# What if the Moon vanished tonight? (2026-10-24)
| claim | value | source |
|---|---|---|
| light delay | 384,400 km / c = 1.28 s ("1.3 s") | basic physics (LLR distance) |
| full moon vs starlight | full moon ~0.05-0.3 lux (0.25 overhead), clear moonless night ~0.002 lux => "up to ~100x" | Wikipedia "Orders of magnitude (illuminance)" / standard values |
| tides | without Moon about one third as high (Sun's tide remains) | AIP Inside Science, "What would happen if there were no Moon" (2015) |

| axis tilt | Moon stabilises tilt; without it tilt could vary a lot, but over millions of years, not instantly | Laskar et al. 1993 (Nature), AIP |
| day length | stays ~24 h; Moon's tidal braking only adds ~2 ms/century | standard |
| recession | ~3.8 cm/year (lunar laser ranging) | NASA / Apollo reflectors |
